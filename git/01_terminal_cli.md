# ターミナル・CLI 操作チートシート

---

## 1. ディレクトリ操作

| コマンド | 説明 |
|---|---|
| `pwd` | 現在のディレクトリを表示 |
| `ls` | ファイル・ディレクトリ一覧を表示 |
| `ls -la` | 隠しファイル含む詳細一覧（権限・サイズ・日時） |
| `ls -lh` | サイズを人間が読みやすい形式で表示 |
| `cd <ディレクトリ>` | ディレクトリを移動 |
| `cd ..` | 一つ上のディレクトリへ移動 |
| `cd ~` | ホームディレクトリへ移動 |
| `cd -` | 直前のディレクトリへ戻る |
| `mkdir <名前>` | ディレクトリを作成 |
| `mkdir -p a/b/c` | 中間ディレクトリも含めて一括作成 |
| `rmdir <名前>` | 空のディレクトリを削除 |
| `tree` | ディレクトリ構造をツリー表示 |
| `tree -L 2` | 深さ2まで表示 |

## 2. ファイル操作

| コマンド | 説明 |
|---|---|
| `touch <ファイル>` | 空ファイルを作成（タイムスタンプ更新にも） |
| `cp <元> <先>` | ファイルをコピー |
| `cp -r <元ディレクトリ> <先>` | ディレクトリごとコピー |
| `mv <元> <先>` | ファイルを移動・リネーム |
| `rm <ファイル>` | ファイルを削除（**元に戻せない**） |
| `rm -r <ディレクトリ>` | ディレクトリごと削除（**要注意**） |
| `rm -rf <ディレクトリ>` | 強制削除（**絶対に確認してから実行**） |
| `ln -s <元> <リンク名>` | シンボリックリンクを作成 |

## 3. ファイルの中身を見る

| コマンド | 説明 |
|---|---|
| `cat <ファイル>` | ファイル全体を表示 |
| `less <ファイル>` | スクロールしながら表示（`q` で終了） |
| `head <ファイル>` | 先頭10行を表示 |
| `head -n 20 <ファイル>` | 先頭20行を表示 |
| `tail <ファイル>` | 末尾10行を表示 |
| `tail -f <ファイル>` | リアルタイムで末尾を追跡（ログ監視に便利） |
| `wc -l <ファイル>` | 行数を表示 |

## 4. テキスト検索・加工

| コマンド | 説明 |
|---|---|
| `grep "文字列" <ファイル>` | ファイル内を検索 |
| `grep -r "文字列" <ディレクトリ>` | ディレクトリ内を再帰的に検索 |
| `grep -i "文字列" <ファイル>` | 大文字小文字を無視して検索 |
| `grep -n "文字列" <ファイル>` | 行番号付きで表示 |
| `grep -v "文字列" <ファイル>` | 一致しない行を表示 |
| `grep -E "正規表現" <ファイル>` | 正規表現で検索 |
| `find <ディレクトリ> -name "*.txt"` | ファイル名で検索 |
| `find . -type f -mtime -1` | 1日以内に変更されたファイルを検索 |
| `find . -size +1M` | 1MB以上のファイルを検索 |
| `sort <ファイル>` | 行をソート |
| `sort -r <ファイル>` | 逆順にソート |
| `uniq` | 連続する重複行を削除（sortと組み合わせて使う） |
| `cut -d "," -f 1` | CSVの1列目だけ抽出 |
| `awk '{print $1}'` | 空白区切りの1列目を表示 |
| `sed 's/before/after/g' <ファイル>` | 文字列を置換して表示 |

## 5. パイプ・リダイレクト

| 記法 | 説明 |
|---|---|
| `コマンドA \| コマンドB` | AのOutput をBに渡す |
| `コマンド > ファイル` | 結果をファイルに書き出し（上書き） |
| `コマンド >> ファイル` | 結果をファイルに追記 |
| `コマンド 2> ファイル` | エラー出力をファイルに書き出し |
| `コマンド 2>&1` | 標準エラーを標準出力に合流 |
| `コマンド < ファイル` | ファイルを入力として渡す |

### よく使う組み合わせ例

```bash
# ログからエラーだけ抽出して件数を数える
grep "ERROR" app.log | wc -l

# プロセス一覧から特定のプロセスを探す
ps aux | grep python

# ディレクトリ内のファイル数を数える
ls | wc -l

# コマンドの結果をファイルに保存しながら画面にも表示
コマンド | tee output.txt
```

## 8. ファイル権限

```
-rwxr-xr--  1  user  group  1234  Jan 1  file.sh
 |||||||||||
 ||||||||||└── その他のユーザー: r(読)--
 |||||||└───── グループ: r(読)x(実)--
 ||||└──────── 所有者: r(読)w(書)x(実)
 └──────────── ファイルタイプ: -(ファイル) d(ディレクトリ) l(リンク)
```

| コマンド | 説明 |
|---|---|
| `chmod 755 <ファイル>` | 権限を数値で設定 |
| `chmod +x <ファイル>` | 実行権限を追加 |
| `chmod -r <ファイル>` | 読み取り権限を削除 |
| `chown user:group <ファイル>` | 所有者を変更 |
| `sudo <コマンド>` | 管理者権限で実行 |
| `sudo su` | rootユーザーに切り替え |

### 権限の数値早見表

| 数値 | 権限 | 意味 |
|---|---|---|
| 7 | rwx | 読・書・実行 |
| 6 | rw- | 読・書 |
| 5 | r-x | 読・実行 |
| 4 | r-- | 読のみ |
| 0 | --- | なし |

よく使う組み合わせ：`755`（スクリプト）、`644`（テキストファイル）、`600`（秘密鍵）

## 9. 環境変数・シェル設定

| コマンド | 説明 |
|---|---|
| `echo $PATH` | PATH環境変数を表示 |
| `echo $HOME` | ホームディレクトリのパスを表示 |
| `export MY_VAR="値"` | 環境変数を設定（セッション内のみ） |
| `env` | 全環境変数を表示 |
| `which <コマンド>` | コマンドのパスを表示 |
| `alias ll='ls -la'` | エイリアスを設定（セッション内のみ） |
| `source ~/.bashrc` | 設定ファイルを再読み込み |
| `history` | コマンド履歴を表示 |
| `!!` | 直前のコマンドを再実行 |
| `!<番号>` | history番号のコマンドを実行 |
| `Ctrl + R` | コマンド履歴をインクリメンタル検索 |

### 設定を永続化する（.bashrc / .zshrc）

```bash
# ~/.bashrc または ~/.zshrc に追記

export MY_API_KEY="xxxxx"        # 環境変数
alias gs='git status'            # よく使うエイリアス
alias ll='ls -la'
export PATH="$HOME/.local/bin:$PATH"  # PATHに追加
```

設定を反映：
```bash
source ~/.bashrc   # bash
source ~/.zshrc    # zsh
```

## 12. シェルスクリプト基礎

```bash
#!/bin/bash
# 先頭にシェバン行を書く

# 変数
NAME="Fruehling"
echo "Hello, $NAME"

# 条件分岐
if [ -f "file.txt" ]; then
    echo "ファイルが存在します"
else
    echo "存在しません"
fi

# ループ
for i in 1 2 3; do
    echo "count: $i"
done

# コマンドの実行結果を変数に格納
DATE=$(date)
echo "今日は $DATE"

# 関数
greet() {
    echo "Hello, $1"
}
greet "world"
```

実行権限を付けて実行：
```bash
chmod +x script.sh
./script.sh
```
